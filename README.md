# PocketWise AI

**AI-powered pocket money and expense management for university and hostel students.**

PocketWise AI helps students record income and expenses, plan monthly allowances, understand spending patterns, and work out how much they can safely spend before their next pocket money arrives. It combines reliable server-side calculations with Google Gemini-powered suggestions.

> **Status:** Portfolio project. Source code is available; a public live deployment is not currently provided.

## Features

- **Student accounts:** Registration, sign-in, sign-out, and protected user-specific pages with NextAuth credentials authentication.
- **Monthly budgets:** Set a monthly allowance, additional pocket money, and a spending limit; review budgets by month.
- **Transactions:** Create, edit, delete, search, and filter income and expense records. Monetary transaction amounts are stored as integer paisa for reliable calculations.
- **Analytics:** Track balances, spending trends, expense categories, budget progress, and alerts.
- **AI category suggestions:** Gemini suggests a category from the app's allowed categories; the student confirms or overrides it before saving.
- **AI monthly insights:** Gemini generates concise, personalized recommendations from validated aggregated spending data, with user-scoped caching.
- **Pocket Money Survival Planner:** Set the next allowance date and reserve unpaid essentials. The app calculates a suggested daily discretionary spending amount without relying on AI for arithmetic.
- **Responsive UI:** Designed for desktop and mobile browsers.

## How it works

1. A student creates an account and signs in.
2. They enter a monthly budget and record income and expenses.
3. The dashboard calculates balances and displays charts and budget alerts using the student's own data.
4. Gemini can suggest expense categories and generate spending insights. AI responses are validated; expense entry remains possible without AI.
5. The Survival Planner combines the remaining balance, unpaid essentials, and next allowance date to estimate a daily discretionary spending limit.

**Important:** Financial totals, percentages, and daily limits are computed by application code, not generated by the AI model.

## Run locally

**Prerequisites:** Node.js compatible with the project's Next.js version, npm, a MongoDB Atlas database, and a Gemini API key if you want to use the AI features.

```bash
git clone https://github.com/areebashfaq30/pocketwise-ai.git
cd pocketwise-ai
npm install
```

Create a `.env.local` file in the project root with your own values:

```dotenv
MONGODB_URI=your_mongodb_atlas_connection_string
NEXTAUTH_SECRET=your_long_random_auth_secret
NEXTAUTH_URL=http://localhost:3000
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=your_accessible_gemini_model
```

Check the current code and hosting configuration for any additional environment variables, such as trusted proxy/IP header configuration for production rate limiting. **Never commit `.env.local` or real secrets.**

Start the app:

```bash
npm run dev
```

Then open **http://localhost:3000**.

## Privacy and security notes

- User-specific database queries are scoped to the authenticated account.
- Passwords are stored as secure hashes, not plaintext.
- Gemini credentials stay on the server, and AI receives aggregate financial data for monthly insights.
- The app validates input and output rather than allowing AI to modify financial records directly.
- Review the existing process-local rate limiter and trusted-IP configuration before any public, multi-instance production deployment.
